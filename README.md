# Кандидатогенерация для категории «Услуги» (Авито)

Тестовое задание Data Science Bootcamp 2026.

По поисковому запросу нужно отобрать из корпуса в 189 тыс. объявлений до 50 кандидатов для дальнейшего ранжирования. Метрика — Recall@50.

**Результат: Recall@50 = 0.7477** на платформе (0.8335 на локальной валидации).

## Подход

BM25 по тексту объявления + приоритет объявлений из локации запроса.

- Текст объявления: заголовок (вес 2) + параметры + первые 1000 символов описания. Слова приводятся к основе стеммером Snowball.
- Текст запроса: сам запрос + фильтры поиска («Вид услуги …»), они совпадают по словам с параметрами объявлений.
- Из 50 мест 40 получают лучшие по BM25 объявления из локации запроса, остальные 10 — лучшие по всему корпусу. Если набралось меньше 50, добиваю популярными объявлениями локации.
- BM25 написан сам на разреженных матрицах scipy: скоры для пачки запросов считаются одним умножением матриц.

Почему так. По train в 83% случаев выбранное объявление находится в той же локации, что и запрос. Без учёта локации recall на валидации 0.32, с ним 0.83.

## Валидация

Train группирую по (запрос, локация, фильтры) и откладываю 3000 групп; правильные ответы — выбранные в группе объявления. Их почти нет в корпусе (из train в корпусе только 6.6% объявлений), поэтому добавляю их туда. Из-за этого валидация оптимистичнее платформы, но для сравнения вариантов подходит.

| n_local | без фильтров | с фильтрами |
|---|---|---|
| 0 | 0.3179 | 0.3202 |
| 30 | 0.8153 | 0.8289 |
| **40** | 0.8181 | **0.8335** |
| 45 | 0.8187 | 0.8326 |
| 50 | 0.8179 | 0.8312 |

## Анализ ошибок

Из 3974 правильных объявлений на валидации в топ-50 не попали 680:

- **63% — объявление из другой локации.** Текст часто совпадает хорошо, но объявление не проходит в 10 общих мест. Похоже на соседние населённые пункты. Поэтому локация не жёсткий фильтр: часть мест остаётся на весь корпус.
- **30% — проиграло конкурентам в своей локации.** Медиана места 83 при отсечке 40, локации большие.
- **6.5% — нет общих слов с запросом.** Разное написание (риелтор / риэлтор), составные слова (пескоструйка, антикор), синонимы.

Что пробовал и что можно сделать дальше:

- эмбеддинги `multilingual-e5-base` + слияние с BM25 через Reciprocal Rank Fusion: на валидации 0.8488 (+1.5 п.п.), в итоговую версию не вошло из-за нехватки памяти в Colab;
- близость по координатам объявления вместо точного совпадения `location_id`;
- символьные n-граммы против опечаток и разных написаний.
